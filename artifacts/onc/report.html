Program Committees

Track 2.3 · epistemological agents · ARC-AGI-3 and ONC-AGI

A committee of programs that knows when it is guessing

OPINE-World learns an unknown game by writing one program that replays everything it has seen. We keep several such programs, each steered toward a different explanation, and read the agent's uncertainty off their disagreement. This page gives every direction that was built and its status, the algorithm as implemented, what it measured on eight levels of six games, how the loop closes when the committee is refuted, what happened when the committee played the game live, and the same method on a science benchmark. Every number points to an entry in RESULTS.md.

Updated 2026-10-03, evening. New since version 6: the map of directions, the closed loop (R23, R24), live play (R25, R26), the replication on four new games (R27), the probe-policy check (R28), the selective score for abstention and its sensitivities (R29, R30), and the revised reading at the end.

The idea in plain words

The agent watches a game for a while. Every move is recorded as a before picture, an action, and an after picture. A program synthesizer writes Python code that takes the before picture and the action and must return the after picture, exactly, for every recorded move. A program that does this is admitted. A program that misses one move is rejected.

Many different programs can pass that test. They agree on everything that was seen, because they must. They differ on what they expect in situations that have not been seen yet. OPINE-World keeps one program and uses it. We keep eight, give each a different hint about what the hidden rule might be, and keep every one that passes. Then:

When the eight programs agree on what happens next, the agent treats the prediction as solid. When they split, the agent treats that situation as unknown, and that is where it spends its next move. If a move proves all eight wrong, the agent knows it needs a new idea and asks for new programs.

Every surviving program counts equally, in the vote and in the disagreement. We tried weighting by program length, the usual simplicity prior, and found that on this data shorter programs were not the ones that generalised, so the weight is off by default and kept only as an ablation.

The algorithm as implemented

1
Transitions and objects. A level's recording gives transitions \((s, a, s')\). A fixed extractor turns each 64×64 frame into a list of objects, each with a type \(\tau\), a position, size, tags and sometimes pixels. We use the extractor that OPINE-World's released run produced for each game, unchanged.
committee.loader
2
Effect rows and the count-based ontology error. Each object's change under an action is reduced to an effect: the sorted list of fields that changed, or no_change, born, gone. Object transitions are filed into rows keyed by type, action and local context \(j=(\tau,a,\mu)\), where \(\mu\) is the sorted types of touching neighbours, plus hit when a click lands on the object. Row counts \(c_j\) with a symmetric Dirichlet prior give OPINE-World's uncertainty:
\[ q_j \sim \mathrm{Dir}(\alpha_0 \mathbf 1 + c_j), \qquad \eta_{\text{counts}}(j) = \frac{H(\mathbb E[q_j])}{\log m}, \]
with \(m\) the number of effects seen anywhere. A row with no observations has no \(c_j\), so \(\eta_{\text{counts}}\) is undefined there. We compute this exactly as a baseline signal.
committee.matrix
3
Split. Train is the first 40% of a level's transitions in time order, test is the rest. RESET and level-closing transitions are removed from both, because their outcome is a new layout and not a function of the state. Nothing from test is ever shown to a synthesizer.
committee.loader.temporal_split
4
Seeded synthesis. \(K=8\) synthesis runs. Each run gets the train transitions, the program contract, and one seed sentence: a different place to look for the hidden rule (object fields, neighbours, a HUD counter, click position, hidden state carried across steps, lattice geometry, blocked moves, symmetry). The synthesizer is an agent with a checker in its loop. A run returns a program \(f_k\). It is admitted only if
\[ f_k(s,a) = s' \quad \text{for every } (s,a,s') \in D_{\text{train}}, \]
compared as a multiset of objects with every field equal. Programs that read files, the buffer, or use exec, eval or pickle are rejected before running.
committee.seeds · committee.synth_devin · committee.verify
5
Weights. Every admitted program has likelihood one, so only a prior could rank them. The default is no prior: \(w_k = 1/K\). An MDL prior \(w_k \propto e^{-\lambda L_k}\), with \(L_k\) the gzip length of the stripped source, is kept as an ablation. Across 45 admitted programs no complexity measure (gzip length, AST size, branch count, literal mass) correlated with held-out accuracy, and on ar25 the best program was among the longest (RESULTS R14).
committee.committee.Committee(lam=0)
6
Prediction and disagreement. For a new \((s,a)\) each member predicts \(f_k(s,a)\). Group identical predictions. The committee's prediction is the largest group. Its disagreement is the normalised entropy of the groups:
\[ u(s,a) = -\frac{1}{\log K}\sum_{g} \frac{n_g}{K}\log\frac{n_g}{K}, \]
where \(n_g\) is the number of members in group \(g\). \(u=0\) when all agree, \(u=1\) when all differ. The same grouping gives each effect row an entropy \(\eta_{\text{committee}}(j)\) over the effects the members predict for the objects in that row, including rows that have no train counts.
committee.committee.Committee
7
Exploration by disagreement. Among the transitions not yet observed, probe the one with the largest \(u\). Observe its outcome. Drop every member that predicted it wrongly. Repeat. If no member survives a probe, the committee is falsified: the agent has evidence that none of its hypotheses is right and must synthesize again. In the offline experiment the probes are drawn from the held-out transitions, and the comparison orders are OPINE-World's count priority (probe the row with the fewest train counts) and random.
committee.explore

Where this differs from OPINE-World

Same object-centric representation, same exact-replay admission rule, same effect rows. The changes are in how many programs are kept, how they are combined, and what drives exploration. Two parts of OPINE-World are frozen rather than reimplemented.

Uncertainty over mechanisms

A transition-level flag says "this move is uncertain". An agent also needs "this rule is uncertain". Two views give that. First, each effect row (object type, action, neighbourhood) gets the committee's entropy over the effects its members predict for the objects in that row, including rows never seen in training. The question is whether that entropy predicts which rows contain errors on held-out data, against OPINE-World's count-based η on the rows that have counts (RESULTS R13, R17, R21).

LevelRows touched (unseen in train)AUROC, committee entropy → row has errorsSeen rows: counts η vs committee ηZero-entropy rows: n, error rateHigh-entropy rows (η > 0.5): n, error rate

Rows where the members agree are almost error-free on every level. On three of four levels the count-based η is at chance or worse on the same rows, because its counts come from training and the errors are on test; on ar25 L7 the two are equal. The committee also scores the rows that have no counts at all, 51 of 90 on ar25 L3 and 186 of 267 on ar25 L7.

Second, one synthesis call extracted a library of the mechanisms the ar25 level 3 programs implement: 15 named functions and a map from each member to the mechanisms it uses (RESULTS R19). The share of members implementing each mechanism is a direct uncertainty over the rule itself.

Uncertainty over trajectories

In play the agent has only its own predictions between observations. Each member was run on its own previous prediction with the real actions, resynchronised to the observed state only at a level entry (RESULTS R15). Two things are measured by horizon, the number of steps since the last observation: how many members are still exactly right, and how far the members have drifted from each other.

LevelHorizon 2 to 5: vote accuracy, teacher forced → open loop6 to 1011+Disagreement 11+, teacher forced → open loop

Is the uncertainty a probability?

Disagreement ranks steps well, but a rank is not a probability. Pooled over the four informative levels the plurality's vote share is overconfident: a share of 0.66 is right 16% of the time, a unanimous vote 86% to 100%. ECE 0.22, Brier 0.18. A calibration map fit on other levels helps on two levels and hurts on two, because the agreed-but-wrong rate moves from 0.00 to 0.30 between levels (RESULTS R22).

What does hold is an online guarantee. Adaptive conformal inference (ACI; Gibbs and Candès 2021) leaves the shares as they are and turns them into a prediction set with a guaranteed long-run miss rate. At each held-out step the committee offers candidate next states, each with the share of members that predict it.

How the wrapper decides

1
Score. Once the outcome \(s'_t\) is seen, its nonconformity is
\[ r_t = 1 - \text{share}_t(s'_t), \]
0 when every member predicted it, 1 when none did.
2
Set. Before the outcome, the set holds every candidate whose score would be at most \(\hat q_t\), the \((1-\alpha_t)\) quantile of the scores seen so far. A set of one state is a committed prediction. When \(\hat q_t\) reaches 1, an outcome no member predicted also falls inside the set, and the wrapper abstains: "one of these, or something none of my hypotheses predicts." An abstention is covered by construction.
3
Adapt. After every step,
\[ \alpha_{t+1} = \alpha_t + \gamma\,(\alpha - \mathrm{err}_t), \qquad \alpha = 0.10, \]
with \(\mathrm{err}_t = 1\) on a miss. A miss lowers \(\alpha_t\) and widens the next sets; a run of hits raises it and narrows them. If \(\alpha_t\) passes 1 the set is empty, a forced miss. That happened on 6 of 221 steps.

The guarantee is that the miss rate on the sequence actually seen tends to \(\alpha\), with no assumption that steps are exchangeable. The only inputs are candidates with shares and the observed outcome, so the wrapper carries to any environment.

Coverage is within two points of target on every level, pooled 0.93 over 221 steps. It is bought in two different ways. Where the committee is mostly right, it comes from committed predictions, which are right 87% to 88% of the time. Where the committee is mostly wrong, it comes from abstaining on 84% and 97% of steps. That abstention rate is the honest number there: it is how often the agent should distrust every hypothesis it holds and go observe instead.

This is why coverage alone cannot be a reward. An agent paid for coverage learns to abstain on every step and scores 1. What matters is coverage together with the share of steps on which the agent commits. A proper scoring rule over the same predictions, with a price on abstaining, combines the two into one number; the next subsection does that.

Abstention is a floor, not a score

Coverage alone rewards abstaining. To price it, score each step of the wrapper: a committed single-state answer earns +1 if right and -1 if wrong; a set of several states or an abstention earns 0 (RESULTS R29). Abstaining throughout scores 0, always committing to the plurality scores 2 x vote accuracy - 1, and confident failure is negative.

What turns abstention into score is the loop, not the wrapper: the live counterexample round lifts the commit share from 0.44 to 0.78 and the selective score from 0.35 to 0.65 on the same game. The abstention region is the map of where to collect counterexamples; resynthesis cashes them. That is also the shape of a training signal: it rewards turning an abstention into a correct commitment, penalises a wrong commitment, and is indifferent to abstaining, so an agent paid by it has one way up, to observe where it abstains and repair its hypotheses. In this project the repair step is the counterexample round; the ONC build trains a decision policy on the same shape. Training the synthesizer itself on it is the open item.

Two sensitivities of that score

The wrapper's step size and the price of a wrong commitment were both fixed by convention, so both were varied (RESULTS R30). A larger step, gamma 0.3 instead of 0.05, chosen leave-one-level-out and the same choice for every held-out level, raises the commit share where the committee is mostly wrong (ar25 L7 from 1 to 23 percent, g50t L1 from 12 to 27 percent) with coverage still at or above 0.90, and changes nothing where it is mostly right. ka59 L2 does not move: its seven members show six behaviours, so no single state ever carries the quantile, and committing needs a calibration map from vote share to probability rather than a wider step. The price decides the policy: at half the reward for a wrong commitment, always committing beats the wrapper on five of seven levels; at an equal price the wrapper wins five of seven; at double it wins the same five by more. The wrapper is the right policy when a wrong answer costs at least what a right one earns, which is the setting of an agent that acts on its prediction.

Closing the loop: refute, then resynthesize

Two facts set this up (RESULTS R23). First, on every level the accuracy an oracle would get by picking the right member per transition equals the best single member's accuracy, so no weighting or selection scheme over the eight programs can beat the best one; the problem is hypotheses that are absent, not hypotheses that are badly combined. Second, on every level the first disagreement probe refutes every member at once, so probing never selects among programs; it only signals that a hypothesis is missing. The repair has to be synthesis.

A counterexample round does that (R24). The refuting probes join the train set, each seed states the refuting transition and what the refuted programs predicted for it, grouped by prediction, and eight new programs are synthesized under the unchanged contract. The control is a passive committee of eight on the next transition in time instead, as an agent that keeps playing rather than probing. Every arm is scored on the transitions no arm observed. On ar25 level 3 a third round starts from the second: it is refuted after three more probes and trains on 33 transitions.

Where it works. On ar25 L3 the members' own notes name the mechanic the counterexample exposed: pieces do not block the axis, which moves onto and under piece rows. The vote goes 0.48 to 0.93, and a third round with four observations in total reaches 1.00 on the 40 remaining transitions and is never refuted again. sk48 L2 goes 0.70 to 0.86. The passive control at the same train size moves 0.00 to -0.06 and stays as spread as before.

Where it does not. Where the members already agree and are wrong together (m0r0 L3, ar25 L7, ls20 L3) one counterexample changes nothing. On ka59 L2 it loses: all seven new programs converge on the same wrong repair, 0.86 to 0.69, unanimous and wrong on 31 percent. On g50t L1 it raises admission from 4 to 7 and the next refutation from probe 1 to probe 6, with the vote at 0.47 to 0.49. Over the seven levels: two clear lifts, three nulls, one marginal, one loss.

The cost. Every resynthesized committee has one or two distinct behaviours, so the disagreement AUROC falls to 0.47 to 0.65 and cannot be read as before. After a round the uncertainty signal has to be rebuilt, with new seeds or a probe chosen by another criterion. One batch of eight per arm; the batch spread is visible in the passive arms.

Live play: the committee as the explorer

With an ARC-AGI-3 key the game runs locally through the official engine (RESULTS R25, R26). The engine is set to level 3 of ar25, whose start state equals the recorded one. Each move, every member predicts the outcome of every available action from the observed object state. The agent takes the action with the highest vote entropy; when every action is unanimous it prefers an action whose predicted state is new, then one that changes the state, and it never repeats a state-action pair. For the scored trajectory each member runs in one persistent process, so a program keeps its hidden state between moves as it does in the offline verifier. The game ends itself after about 160 moves.

All three committees are unanimous and right for the first 64 moves on both trajectories. Then the counter bar starts to shrink by one per action, a mechanic absent from all 75 recorded transitions of the level, and every later state carries it. Round 1 and round 3 are refuted at move 64 with disagreement 0.00: an unknown unknown that no flag catches and the cue for resynthesis with the observed transition as the counterexample.

The live round's members all replay the 104 transitions (33 recorded plus 71 live), and their notes state the rule: a hidden move budget of 128 whose bar displays the smaller of the budget and 64. Live, they predict the tick and every move through 69 on seed 0, and the vote rises from 0.40 to 0.71 and 0.86. The next refutation is an action 3 mechanic at moves 70 and 81; from about move 110 every prediction fails again. That is the next counterexample.

What to take from it, and what not

Take. Disagreement between exact-fit programs is an honest flag on eight levels of six games and on a live trajectory. It is defined for situations that have never been seen, where the count-based measure has nothing to say; it finds the refuting observation in one probe; and the conformal wrapper turns it into sets that hold a 0.90 coverage target everywhere, by committing where the committee is right and abstaining where it is not.

Take with its condition. Resynthesis on the refuting observation is the repair, and it works when that observation names one missing mechanic: 0.48 to 1.00 on ar25 L3 in two rounds, 0.70 to 0.86 on sk48 L2, and 0.40 to 0.71 and 0.86 live. On the other five levels it did nothing or lost. The resynthesized committee converges, and a committee that agrees after a counterexample round is the one to distrust.

Do not take. The committee does not predict better than one program; the oracle over its members equals the best member on every level. The shortest program is not the best one. Disagreement does not flag an unknown unknown: when every member shares a blind spot, as with the live move budget, the flag is silent until the observation arrives.

Simplifications. The offline experiments use OPINE-World's released recordings with the object extractor frozen to the one each released run produced; the live runs use the same extractor on the engine's frames. Synthesis is Devin; two open-weight models served on Modal did not reach exact replay on the easiest level in a plain repair loop. One batch of eight programs per arm throughout.

The same method on a science benchmark: ONC-AGI

ONC-AGI poses one question per world: here is a cohort with an outcome; which measurements drive it? The agent returns an ordered list of features, or an empty list, and in sequential mode buys its own data with recruit and assay. The score is Find × Restraint: chance-normalised recovery of the planted drivers, times the difference between abstaining on null worlds and abstaining on signal worlds. Listing a post-outcome feature zeroes the world; overspending the reference cost scales the credit down. Only toy fixture worlds ship today, so every number here is a toy-world or generated-world number, not a benchmark result.

The committee, ported

1
Hypotheses. Eight hypothesis programs, one per causal role family: null, direct, conservative, sparse, confounder-adjusted, upstream cause, interaction and correlated block. Each reads the revealed baseline data and returns an ordered driver set and a logistic model p(y | x). Post-outcome columns are removed before any hypothesis sees the data: the leak filter is a filter, not a learned behaviour.
onc.hypotheses
2
Admission and weights. A hypothesis is admitted when its 5-fold cross-validated log loss, selection step included, is within 0.02 of the best member. The null hypothesis is always a member. Weights are \(w_k \propto e^{-n\,\ell_k}\) with \(\ell_k\) the CV log loss; equal weights are the ablation and give the null member 1/K whatever the data, which costs all of Restraint in full access.
onc.committee.build_committee
3
What it reports. P(signal) is the weight of the non-null members; P(driver = f) is the weight of the members that list f, one vote per correlation cluster; p(y | x) is the weighted mixture. Submission: abstain if P(signal) < 0.5, else list the features with P(driver) ≥ τ in decreasing order. Disagreement U is the normalised entropy over the members' driver sets.
4
Acquisition by disagreement. Recruit 60 patients across strata, assay every baseline feature on them, then recruit 40 more while the expected drop in U per 1000 USD exceeds a threshold and spend stays under the cap. The committee from before each batch is scored on that batch after it is revealed, which gives a true held-out stream of p(y | x) for calibration and conformal coverage. When no non-null member survives, the only repair is more data; that step earns no shaping reward.
onc.agent.CommitteeAgent
5
Reward. \(R = R_{\text{task}} + \lambda_{\text{cal}} R_{\text{cal}} + \lambda_{\text{dis}} R_{\text{dis}}\). The task term is the benchmark's own score written per episode. The calibration term is minus the Brier score of P(signal), of P(driver) over the listed features, and of p(y | x) on the held-out patients. The shaping term is the drop in disagreement, \(U_{t-1} - U_t\), potential-based so it telescopes to \(U_0 - U_T\) and cannot be farmed; the policy cannot touch the committee, so it cannot lower U by fiat.

Glossary

Transition
One recorded move: before state, action, after state.
Exact replay
A program reproduces every recorded after state, every field of every object.
Effect row
All object transitions with the same object type, action and neighbourhood.
Ontology error η
OPINE-World's uncertainty: how mixed a row's effects are, from counts.
Committee
The admitted programs, with a weight each.
Disagreement
How spread the members' predictions are for one new transition, 0 to 1.
Falsified
An observed outcome that no member predicted. Time to synthesize again.
Counterexample round
Resynthesis after a refutation: the refuting observations join train and each seed states them.
Agreed but wrong
A unanimous prediction that is wrong. The failure the flag cannot see.
Live round
A counterexample round whose refuting observations come from the agent's own play.
