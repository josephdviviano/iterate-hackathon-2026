## Details (full outcome and post-mortem, condensed above)

### Outcome
accuracy 0.7372 (0.7352, 0.7348, 0.7416) vs tip estimate 0.7554: -1.82 pp; time 5.377 s vs 5.501: -2.3% (-0.124 s,
i.e. one NS iteration costs ~0.32 ms/step x 384). Verdict refutes. Contingency "opposite way": orthogonalization
quality matters a lot. With 2 iterations of the quintic (3.4445, -4.7750, 2.0315), singular values are still far from
1, so Muon's update is much less "whitened".
Implication (opposite direction): if 2 -> 3 iterations is worth +1.8 pp for +2.3% time, then 3 -> 4 (or 5) may still
buy a few tenths of a pp for ~+2.3% time each -- a better exchange rate than any epoch change (0.035-0.08 pp per 1%)
if the gain is >= 0.1 pp. That headroom could then pay for a 3rd/4th 16 px epoch (E029: -0.27 s for -0.3 pp).

### Post-mortem
Predicted accuracy [0.751, 0.758] -> miss (0.7372). I assumed Muon is robust to rough orthogonalization (as reported
for NanoGPT-scale Muon with 5 steps -> 3); here 2 steps are far too few. Lesson: the NS iteration count is an accuracy
knob, not an overhead knob; probe upward (4-5 steps), not downward.
