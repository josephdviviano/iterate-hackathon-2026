## Pre-registration
- Prediction: accuracy [0.753, 0.760]
- Prediction: time [5.20, 5.30]
- Supports if: the 16 px phase spends >= 30% of its time below 90% of the 400 W cap while the 32 px phase is at >= 95% of the cap for >= 80% of its time (H2.4.1: low-res phases are overhead-bound, not power-bound).
- Refutes if: the 16 px phase is at the cap as much as the 32 px phase.
Instrumentation only (on the current tip E044): CUDA events at epoch boundaries (one event sync at the end of train,
where the harness syncs anyway) and one print per trial; nvidia-smi samples power/SM clock/throttle every 100 ms in a
separate process outside the submission.

## Contingencies
- If it lands in the predicted range: low-res phases are launch/overhead-bound -> CUDA graphs or fewer kernels there pay.
- If it moves the right way but less than predicted: mixed; overhead work only in 16 px phase.
- If it moves the opposite way: all phases power-bound -> only FLOP/byte cuts help anywhere.
- If it crashes: instrumentation bug; fix.
