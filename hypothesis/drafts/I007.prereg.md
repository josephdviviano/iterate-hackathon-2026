## Contingencies
- If it lands in the predicted range: if acc 0.745-0.753, shift the schedule toward 32 px (e.g. 24 only first 25%, 28 to 50%) or +0.5 epoch; progressive resizing has headroom.
- If it moves the right way but less than predicted: (time saving < 10%) interpolation/recompile overhead or BN mismatch -> profile.
- If it moves the opposite way: (acc < 0.735) low-res training hurts CIFAR-100 badly -> try only 28 px for early epochs.
- If it crashes: check compile shapes / interpolate fp16 antialias support; fix and rerun.
