H1 (open, c=0.80): Time is mainly set by sample efficiency: how many epochs/steps the recipe needs to reach >=75.3% (architecture, init, optimizer, schedule, label smoothing, augmentation). Recipes that need fewer epochs dominate the score.
Idea: Explore, as an alternative way to cheapen group 1. Keep 3 convs in group 1 but narrow its width from 128 to 96 channels (96/384/768, or 96/384/576 on the incumbent if the 768 run isn't kept). The whitening conv output and the group-2 input adjust to match. Same epochs, LR rescaled only as airbench's width-independent scaling dictates (unchanged).

If the accuracy loss per second saved is below ~1 pp/s, it beats adding epochs and should be combined with the winner of the group-1 depth cut.
