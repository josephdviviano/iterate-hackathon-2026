So I expect a small gain.

## Contingencies
- If it lands in the predicted range: keep if >= 1% faster (it adds no code complexity, only build time).
- If it moves the right way but less than predicted (< 2%): discard; conv kernels are already near-optimal via cuDNN; per-step gains must come from architecture shape (channel counts, resolution) not compiler mode.
- If it moves the opposite way: discard; note that autotune picked worse kernels or recompiled in the timed region.
- If it crashes (e.g. build timeout or cudagraph errors): try mode="max-autotune-no-cudagraphs".
