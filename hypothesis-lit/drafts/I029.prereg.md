## Pre-registration
On E021 (0.7552 @ 7.62 s). Change: Newton-Schulz 3 -> 2 steps with Turbo-Muon-style AOL preconditioning (rows of X rescaled by 1/sqrt(rowsum |X X^T|) on the small side; the rescaled Gram matrix is reused in the first step, so the preconditioner costs no extra matmul). Same coefficients, lr, momentum.
Dev check on random Gaussian matrices: singular values after precond+2 steps are [0.67, 1.21] (mean 0.92) for 128x216 and [0.67, 1.01] (mean 0.76) for 576x5184, vs 3 plain steps [0.96, 1.20] (mean 1.15) on 576x5184 -> large layers get a ~1/3 smaller effective update at the same lr; plain 2 steps would be much worse (mean 0.47).
- Prediction: accuracy [0.7505, 0.7570]
- Prediction: time [7.45, 7.58]
- Prediction: complete [1, 1]
- Supports if: (H2.5) time drops >= 1% and accuracy >= 0.7535.
- Refutes if: accuracy drops > 0.25 pp (< 0.7527) — the 3rd NS step (or its update magnitude) matters.

## Contingencies
- If it lands in the predicted range and supports: keep.
- If it moves the right way but less than predicted (time drop < 1%): discard; Muon NS cost was not the matmuls but the elementwise/norm parts.
- If it moves the opposite way (accuracy < 0.7527): discard; consider precond + 3 steps only if the update-magnitude explanation is tested (e.g. raising lr ~1.3x) via a future idea.
- If it crashes: tail, fix.
