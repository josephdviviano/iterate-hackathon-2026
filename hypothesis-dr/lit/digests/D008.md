## Larger batch on the Muon tip: what the literature says (H1.2.3)

**Bottom line:** none of the cards measures what H1.2.3 needs: Muon at a fixed number of epochs, in a budget-limited run with only a few hundred steps. The evidence is indirect and mostly from long or very large runs. Treat H1.2.3 as an empirical bet: run it once, pre-register the outcome, and expect a small accuracy cost.

**(a) Muon and batch size**
- **C0085 (conditional):** A one-step theoretical analysis of linear associative memory finds Muon's critical batch size is larger than SGD's. **C0088 (conditional):** in multi-billion-parameter LLM pretraining, Muon stays stable at very large batches where AdamW degrades.
  - Both point the same way, but they come from a toy linear model and from LLMs, not from ~6.5 epochs on CIFAR-100.
  - They support the plan to leave Muon lr unchanged (its updates are normalized). They say nothing about how to set momentum.
- **C0089 and C0090** are about Muon in general, not batch size. They don't bear on this question.

**(b) Fixed-epoch loss, scaling rules and averaging**
- **C0093 and C0094 (conditional):** At the same epoch count, large batches match small batches and save wall-clock time (ImageNet, 90 epochs, TPU). That is the long, data-limited regime.
  - This loop is step-limited. Even 0.25 epoch (about 12 steps) moves the 3-seed mean by about 0.4 pp (E022, E027).
  - At bs 1536 the run drops from ~318 to ~212 steps, and lookahead syncs (every 5 steps) drop from ~64 to ~42.
  - Expect an accuracy loss, not equivalence.
- **C0095 (conditional):** The linear lr scaling rule applies only to the SGD group (BN biases, whitening bias, head).
- **C0096 (conditional):** Accuracy falls once the starting lr is past its optimum. The SGD-group lr of 9 is already a large value inherited from airbench. So multiplying it by 1.5 linearly is risky.
  - Prefer sqrt scaling (×1.22).
  - Keep lr×wd constant.
- **C0092 (conditional, warning):** Raising momentum while scaling batch size cost 0.7 pp even at 90 epochs. Keep Muon momentum at 0.8 and SGD momentum unchanged.
- **Averaging:** no card covers how EMA or lookahead interacts with batch size. With fewer steps, lookahead's horizon in steps shrinks. Consider shortening the sync interval to 3–4 steps so the number of syncs stays about the same.

**Mechanism the tree lacks**
- **C0091 (untested):** For SGD and Adam, increasing the batch size during training is equivalent to decaying the lr, at the same number of epochs.
  - A batch-size ramp could keep the early small-batch steps, where this regime is step-limited, and use large, cheap batches only in the tail, where the lr is already low. For example, bs 1024 for the first ~60%, then bs 2048.
  - Add this as an H1.2 child. Compile both shapes in `build()`.

**What to do next**
1. Run H1.2.3 as specified: bs 1536, Muon lr and momentum unchanged, SGD-group lr ×√1.5, lr×wd constant.
2. Pre-register a time change of −4% to −7% and an accuracy change of −0.2 to −0.5 pp.
3. If the accuracy loss is no more than 0.25 pp, which is within re-draw noise, add about 0.25 epoch and compare at the matched knee.
4. If the loss is above 0.4 pp, mark H1.2.3 refuted for fixed-batch training and try the C0091 ramp instead.

## Claims
- C0085 (conditional; H1.2.3): Theory on a toy linear model says Muon's critical batch size is larger than SGD's. This supports keeping Muon lr unchanged at bs 1536, but it doesn't measure the step-limited ~6.5-epoch regime used here.
- C0088 (conditional; H1.2.3): Muon stays stable at very large LLM batch sizes. This is weak transfer to small-scale CIFAR, and it has nothing to say about momentum scaling.
- C0093 (conditional; H1.2.3): Large batches match small ones at the same epoch count, but only at 90 epochs. This loop is step-limited (E022/E027: about 0.4 pp per 0.25-0.5 epoch), so expect a loss rather than equivalence.
- C0094 (conditional; H1.2.3): Shows the wall-clock gain from fewer steps per epoch. Pre-register a time cut of -4% to -7% for bs 1536.
- C0095 (conditional; H1.2.3): The linear lr scaling rule applies only to the SGD group (BN biases, whitening bias, head), not to Muon.
- C0096 (conditional; H1.2.3, H1.7): Accuracy falls when the starting lr is past its optimum. The SGD-group lr of 9 is already large, so prefer sqrt scaling (x1.22) over linear (x1.5).
- C0092 (conditional; H1.2.3): Raising momentum together with batch size cost 0.7 pp even at 90 epochs. Keep Muon and SGD momentum unchanged when the batch grows.
- C0091 (untested; H1.2, H1.6): Increasing batch size is equivalent to decaying lr. This suggests a new H1.2 child: a batch ramp (bs 1024, then 2048 in the low-lr tail) that keeps the early steps and makes the tail cheaper. It is the fallback if a fixed bs 1536 costs more than 0.4 pp.
