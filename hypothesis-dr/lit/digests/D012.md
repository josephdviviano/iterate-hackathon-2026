# D012: E041 raised the batch size from 1024 to 1536 at 6.5 epochs (about 319 to about 212 steps). Time fell 8% (5.89 to 5.42 s), but accuracy fell 0.18 pp to 0.7533, at the gate with no margin. That is now the main lever, and the E040 resolution curriculum is waiting to stack on top of it. The next experiments need to know three things. (1) With a Muon-style orthogonalized optimizer, how should lr, momentum, warmup fraction and weight averaging (lookahead or EMA horizon and sync interval) scale with batch size, so that accuracy per epoch holds when the run has only about 200 steps? (2) Is bs 1536-2048 still below Muon's critical batch size for a small CNN on a 50k-image dataset? (3) Which accuracy-recovery tricks for large batches would win back about 0.2 pp at a fixed epoch count? Candidates are ghost BN, a momentum or lr re-tune, the averaging rate scaled per sample rather than per step, and a shorter warmup. The answers decide whether to tune bs 1536, push to bs 2048, or go back to 1024 and combine with the curriculum instead.

# Digest: scaling batch size with Muon, and getting back the ~0.2 pp

**Bottom line.** None of the cards measure Muon on a small CNN, and none measure critical batch size on 50k images. Everything below is borrowed from SGD on CIFAR-10 and ImageNet, Adam on language models, or Muon theory.

**(2) Is bs 1536 below the critical batch size?** Probably yes, and the loop's own numbers carry most of that answer.
- **C0154 (explains):** critical batch size is defined as the batch size where steps exceed linear scaling by 20%.
- **E041 on that scale:** it lost 0.18 pp. At the knee slope (~0.9 pp/epoch) that is ~0.2 epoch, about 3% more samples. That is far below the 20% overhead, so 1536 is well inside the efficient regime.
- **C0150/C0153 (conditional):** critical batch size grows with dataset size. Our 50k images argue for a low ceiling, but these are language-model results.
- **C0171 (conditional):** Muon's critical batch size grows as (1+β)². Higher momentum should raise the ceiling, but this is theory only.
- **Implication for 2048:** it is plausible, but the trend can't be extrapolated from one point.

**(1) How should the knobs scale?**
- **Muon lr:**
  - **C0162 (conditional, Adam on language models):** the best lr grows much more slowly than √B, so keeping the Muon lr at 0.16 is defensible.
  - **C0148 (explains, SGD):** per-epoch learning curves stay the same when the noise scale lr·N/B is held. E041 already did this by scaling the SGD-group lr ×1.5.
- **Momentum:**
  - **C0149 (contradicts a naive push):** at a fixed epoch count, raising momentum to 0.975 cost 2 pp.
  - Taken with C0171, the advice is to try momentum 0.85, but not ≥0.9.
- **Warmup:**
  - **C0146 (contradicts the "shorter warmup" candidate):** large batches with momentum are unstable early in training.
  - With only ~212 steps, keep the warmup *fraction* as it is. Don't shorten it.
- **Averaging horizon:**
  - **C0160 (untested mechanism):** hold the averaging horizon fixed in samples, not in steps.
  - At bs 1536, a sync every 5 steps with decay 0.97^5 covers 1.5× more samples per sync. The per-sample-matched decay is 0.97^(5/1.5) per sync.
  - **C0152/C0159 (conditional):** weight averaging helps more at large batch, which suggests averaging is worth tuning at 1536.

**(3) Tricks to win back the accuracy:**
- **Ghost BN, C0147 (untested here):** it keeps batch statistics independent of batch size. BN over 512- or 768-sample groups at bs 1536 is cheap and matches the earlier noise. This is the follow-up already named in H1.2.3.
- **Muon theory, C0166 (conditional):** convergence improves with smaller lr plus larger momentum and batch. A pairing worth trying is Muon lr 0.14 with momentum 0.85.
- **Better optimizer at large batch, C0164 (explains):** the gap between optimizers widens as batch grows. That fits Muon tolerating 1536 at all.

**Recommendation.** Stay at bs 1536, because E042's jitter already restored 0.7549.
1. Stack the E040 curriculum next.
2. Then run one-factor tests: ghost BN, the per-sample lookahead decay, and momentum 0.85.
3. Try bs 2048 only after that, with the same pre-registered refutation rule as H1.2.3.

## Claims
- C0154 (explains; H1.2.3): Use the 20%-step-overhead definition of critical batch size. E041's 0.18 pp loss is about 0.2 epoch (~3% more samples), so bs 1536 is well below the critical batch size. Keep 1536 as the base.
- C0150 (conditional; H1.2.3): Critical batch size grows with dataset size, so a fixed 50k-image set suggests a low ceiling. This comes from language models, so test bs 2048 once rather than assume it works.
- C0171 (conditional; H1.2.3, H1.2): Muon theory says critical batch size grows as (1+β)². Pairing larger batches with slightly higher momentum (0.85) should help.
- C0149 (contradicts; H1.2.3, H1.2): Momentum ≥0.9 at a fixed epoch count cost 2 pp on ImageNet. Cap any momentum re-tune at about 0.85.
- C0146 (contradicts; H1.2.3): Large batches with momentum are unstable early, which argues against the 'shorter warmup' recovery candidate. Keep the warmup fraction.
- C0148 (explains; H1.2.3): Holding the noise scale lr·N/B keeps per-epoch accuracy. This justifies E041's ×1.5 SGD-group lr; keep it.
- C0162 (conditional; H1.2.3): The best lr grows much more slowly than √B. Keeping the Muon lr fixed at 0.16 when raising batch size is reasonable; don't scale it up.
- C0147 (untested; H1.2.3): Ghost BN keeps batch statistics independent of batch size. Test BN over 512- or 768-sample groups at bs 1536 as a one-factor recovery run.
- C0160 (untested; H1.6, H1.6.1, H1.2.3): Hold the averaging horizon fixed in samples, not steps. At bs 1536, set the lookahead per-sync decay to 0.97^(5/1.5) and test it.
- C0152 (conditional; H1.6, H4.2): Weight averaging helps more at large batch (language-model evidence). Prioritize averaging-horizon tuning on the bs 1536 base.
- C0166 (conditional; H1.2.3): Muon convergence improves with smaller lr plus larger momentum and batch. A candidate pairing is Muon lr 0.14 with momentum 0.85.
- C0164 (explains; H1.2, H1.2.3): The gap between optimizers widens with batch size, which fits Muon tolerating bs 1536 with only a small loss. No action needed.
