## Literature digest: untuned Muon hyperparameters at a small epoch count

**First, a correction to the question.** E024 is no longer the tip. E027 and E028 were both kept: 6.75 epochs, about 6.08 s, accuracy 0.7546. The margin over the 0.753 gate is about 0.16 pp, not 0.55 pp. E026 (momentum 0.8) was also kept: +0.18 pp over E024, which is inconclusive under the H4.1 noise rule. Check which of lr 0.16 and momentum 0.8 the E027/E028 commits actually contain before stacking anything on them.

**What the cards say.** The cards give no effect sizes for short-horizon vision runs. They are mostly theory plus validation on LM, CIFAR-10 or ImageNet.

- **(a) Momentum and Nesterov.** Nesterov only slightly tightens Muon's convergence bound and has the same rate as plain momentum (C0084, C0078; conditional, includes CIFAR-10). Keep Nesterov on and don't spend a run toggling it. On the momentum value itself the cards are silent. C0083 says momentum and batch size interact, so they partly substitute for each other.
- **(b) Weight decay on the Muon group.** In theory, weight decay keeps parameter and gradient norms bounded and couples with lr (C0079). The tip's weight-norm projection already bounds norms, which makes that role largely redundant (untested). Cautious WD works with Muon and needs no tuning (C0075–C0077), but it was shown only at LM/ImageNet scale, with no magnitudes given. It is also built to *preserve* the loss rather than regularize it (conditional). There is no tree node for this.
- **(c) Batch size.** Muon's critical batch size scales with momentum β and weight decay λ, but its absolute value can't be predicted (C0080, C0081). There are closed-form power laws for momentum and batch size as a function of training horizon (C0082). Nothing says whether Muon's critical batch size is larger or smaller than SGD's (untested). bs 512 also doubles the per-step Muon/NS overhead.
- **(d) Weight averaging.** **No cards found.** The only evidence is in-loop: averaging is worth about 0.9 pp under Muon (E020), and 0.97^5 decay was neutral (E028).

**Ranking by expected gain at a fixed epoch count (mostly from loop evidence, not the papers):**

1. **Momentum (a).** Cheapest lever, with a weak positive sign already (E026). Rerun 0.8 on the real tip at 6.5 epochs. Try 0.9 only if 0.8 holds. Keep Nesterov.
2. **Averaging cadence (d).** The effect is large but the literature is silent. Try lookahead syncs every 3 steps, or an EMA (about 0.99 per step) over the last 30% of steps on top of lookahead (H1.6.1).
3. **Batch size (c).** Try bs 768, or bs 512 with Muon lr scaled by about 1/√2 to keep total rotation per epoch roughly constant (my own heuristic, not from the cards). Because of C0083, retune momentum afterwards rather than changing both at once.
4. **Muon weight decay (b).** Lowest expected gain. If tried, add CWD to the Muon group and keep the projection, with λ equal to the SGD group's wd.

## Claims
- C0084 (conditional; H1.2): Nesterov vs plain momentum only slightly tightens the bound (tested on CIFAR-10 and LM). Keep Nesterov and don't spend a run toggling it.
- C0078 (conditional; H1.2): Theory says Nesterov changes Muon's convergence behaviour. Together with C0084 the practical difference is small, so it is not a priority lever.
- C0083 (conditional; H1.2, H1.2.1): Momentum and batch size interact and partly substitute for each other. Test momentum 0.8 and bs 512 separately, and retune momentum after any batch-size change.
- C0082 (untested; H1.2): Optimal momentum and batch size depend on the training horizon, and the tip's values were inherited from a longer CIFAR-10 horizon. Supports adding a node for Muon momentum and batch size at about 7 epochs.
- C0080 (untested; H1.2): Muon's critical batch size depends on β and λ but has no absolute value, so nothing says whether it is larger than SGD's. A bs 768 or bs 512 trial must be settled empirically; account for the doubled NS overhead per epoch.
- C0081 (conditional; H1.2): The momentum, wd and batch-size predictions were validated on image classification, but only qualitatively, so treat them as directional guidance only.
- C0079 (untested; H1.2): Weight decay's role in Muon theory is bounding norms, which the tip's weight-norm projection already does. Rank Muon-group wd last.
- C0076 (conditional; H1.2): CWD drops into Muon without tuning. If wd is tried, use CWD with λ equal to the SGD group's wd and keep the projection.
- C0075 (conditional; H1.2): Shown only for LM and ImageNet at scale, with no magnitude given. Low prior for a 7-epoch CIFAR-100 run.
- C0077 (untested; H1.2): CWD preserves the loss rather than regularizing it, so any gain would have to come from optimization, not regularization. Lowest-priority lever.
