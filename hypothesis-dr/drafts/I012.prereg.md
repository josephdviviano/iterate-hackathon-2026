## Contingencies
- If it lands in the predicted range: if accuracy gain >= 0.4 pp, follow with fewer epochs (8 or 8.5) to cash it in;
  if gain < 0.2 pp, discard (overhead with no epoch saving).
- If it moves the right way but less than predicted: (overhead > 15%) consider 3 NS steps / batched NS before discarding H1.2.
- If it moves the opposite way: (accuracy drops) lr/momentum mis-tuned for bs 1024; one retune (lr 0.12 or bs 2048) before dropping.
- If it crashes: likely the compile of NS on variable shapes (recompile limit 8 > 4 distinct shapes, should be OK) or the
  optimizer-list plumbing; fix and relaunch.
