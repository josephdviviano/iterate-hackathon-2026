## Post-mortem
<!-- For failures and missed predictions: what you predicted, what happened, the root cause,
what the world model got wrong, the lesson. -->
Predicted accuracy [0.7535, 0.7560] (bit-near-identical math); got 0.7574. Root cause: I assumed cudagraphs leave numerics unchanged, but switching the compile mode re-runs autotuning and can select different conv/matmul kernels (different reduction orders), so every seed follows a different trajectory. The world model said 'compiled training is deterministic', which is true for a fixed compiled artifact, not across compile configurations. Lesson: any change in compile mode or kernel choice is a seed-like perturbation (+-0.24 pp per seed, +-0.14 pp on the 3-seed mean); don't read accuracy changes below ~0.3 pp from such changes as signal, and use pre-registration ranges at least that wide.
