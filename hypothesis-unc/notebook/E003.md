## Post-mortem
<!-- For failures and missed predictions: what you predicted, what happened, the root cause,
what the world model got wrong, the lesson. -->
Predicted time [7.8, 10.0]; got 12.07 s. Root cause: torch.compile guards on input strides; the warmup batch layout (contiguous NCHW) differed from the training batch layout (channels_last), so the first real step recompiled with max-autotune (~9 s) inside the timed region. The world model assumed 'warm up the shape' was enough; it is shape AND stride AND dtype AND requires_grad. Lesson: warm up with tensors produced by the same code path as training (same layout), and check with TORCH_LOGS=recompiles on random data before launching any compiled change.
